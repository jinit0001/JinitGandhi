# Jinit Gandhi, portfolio

Plain HTML, CSS and JavaScript. No build step.

## Update the live site
Replace the files in your GitHub repository with the ones in this folder (and delete `projects/websites-co-in.html`). Vercel redeploys on its own in about a minute.

## Run it on your computer
Open `index.html` in a browser, or run `npx serve` in this folder.

## Change things
- Text: edit the `.html` files.
- Colours: the variables at the top of `css/style.css`.
- Resume: replace `assets/Jinit_Gandhi_Resume.pdf` (keep the same name).
