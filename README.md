# Jinit Gandhi, portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run it on your computer
Open `index.html` in a browser. Or run `npx serve` in this folder.

## Deploy on Vercel
1. Put this folder in a new GitHub repository.
2. On vercel.com choose Add New, then Project, then import that repository.
3. Framework Preset: **Other**. Leave build command and output directory empty. Deploy.

## Change things
- Text: edit the `.html` files.
- Colours: the variables at the top of `css/style.css`.
- Resume: replace `assets/Jinit_Gandhi_Resume.pdf` with your latest PDF (keep the same name).
